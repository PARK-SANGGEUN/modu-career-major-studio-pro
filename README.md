# 모두의 직업-학과 커리큘럼 상담 스튜디오

교사용 진로·학과 상담 웹앱입니다. GitHub Pages에 올리면 별도 서버 없이 바로 실행됩니다.

## 추천 저장소명
`modu-career-major-studio-pro`

## 구성
- `index.html` : 화면 구조
- `styles.css` : 디자인, 카드, 팝업, 인쇄 리포트 서식
- `app.js` : 직업 데이터, 검색, 팝업, 비교, 메모 저장, 출력 기능

## 주요 기능
- 직업 프로필 620개
- 직업별 SVG 일러스트 자동 생성: 복장, 도구, 움직임 요소 반영
- 카드 클릭 상세 팝업
- 관련 학과, 대학 커리큘럼, 배우는 내용 제공
- 2015 개정 고교 과목 / 2022 개정 고교 과목 분리 표시
- 최대 4개 직업 비교
- 상담 메모 저장/불러오기
- 학생 리포트 인쇄 출력
- 화면 톤 전환

## 참고 구조
- 커리어넷 학과정보/직업정보
- 대입정보포털 어디가 학과정보
- 서울진로진학정보센터 대학별 전공 안내
- 대학별 전공가이드북의 교육과정/전공역량/진로 안내 형식
- NCS 직무 분류 체계

※ 실제 대학별 세부 교육과정은 대학·학과 홈페이지와 최신 전공가이드북으로 최종 확인해야 합니다.
