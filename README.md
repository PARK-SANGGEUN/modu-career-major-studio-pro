## GitHub Pages 사용법
1. 새 저장소를 `modu-career-major-studio-neo` 이름으로 생성
2. 이 ZIP의 파일을 압축 해제 후 저장소 루트에 업로드
3. Settings → Pages → Deploy from branch → main / root 선택
4. 배포 주소 접속
